## 2. 한 문단 소개

> 누구나 어릴 때 해 본 바둑알 "알까기"를, 실제처럼 움직이는 물리 엔진과 무협 이야기로 다시 만든 모바일 게임입니다.
> 돌의 위·가운데·아래 어디를 튕기느냐에 따라 밀어치기·강타·끌어치기가 달라지고, 재질(청옥·나무·현철·얼음)과 모양(납작·둥근·구형)에 따라 손맛이 바뀝니다.
> 초행자가 마을마다 고수를 만나며 궁극기 '어기어석'을 깨우치는 6장 이야기, 매일 조금씩 해야 빨리 크는 수련, 아주 낮은 확률로 찾아오는 기연이 오래 즐기게 합니다.

## 3. 기획 의도

- **누구나 아는 놀이:** 알까기는 규칙 설명이 필요 없다. 처음 하는 사람도 바로 시작한다.
- **진짜 같은 손맛:** 화면 속 돌이 실제 돌처럼 움직여야 재미가 산다. 이 부분을 직접 만든 물리 모델로 해결한다(§4).
- **오래 즐기는 구조:** 하루에 몰아서 하는 사람보다 매일 조금씩 하는 사람이 훨씬 빨리 성장한다. 피로도가 낮고, 매일 들어올 이유가 생긴다.

## 4. 차별성 (현재 확인된 근거와 함께)

| 차별점 | 내용 | 근거 |
|---|---|---|
| 상·중·하 타격 | 2D 물리 엔진에는 없는 앞뒤 회전을 직접 구현했다. 가까운 표적일수록 효과가 크고 멀면 줄어 실제 당구 같은 요령이 생긴다 | [실측] 표적 8cm: 밀어치기 +5.2cm / 끌어치기 −7.0cm (차이 12cm), 표적 20cm: 차이 1cm |
| 재질·모양에 따른 손맛 | 같은 힘으로 굴렸을 때 재질마다 거리가 크게 다르다 | [실측] 청옥 12.7cm · 나무 34.5cm · 현철 2.9cm · 얼음은 판 밖으로 |
| 꾸준함 보상 | 하루 처음 30타는 3배, 그 뒤는 10% | [계산] 30일 매일 30타 = 2,700 vs 하루 900타 몰아치기 = 177 |
| 공정한 대전 | 서버가 모든 판정을 다시 계산. 주말 토너먼트는 모두 같은 기본 돌만 사용 | [실측] 같은 입력 200판 결과 200/200 동일 |
| 무협 연출 | 강한 충돌 때 캐릭터 환영이 맞붙는 연출, 문파별 결정타 | 설계서 §4 |

## 5. 대상 이용자

- **주 대상:** 짧은 시간에 즐길 캐주얼 대전을 찾는 모바일 이용자, 알까기를 해 본 세대
- **확장:** 무협 이야기를 좋아하는 이용자, 실력 경쟁(랭킹·토너먼트)을 즐기는 이용자
- 【형】 기능성게임 트랙에 낼 경우 추가: 어르신 손 운동·인지 훈련(설계 추가 필요 — 지원사업 README §3 참고)

## 6. 핵심 콘텐츠 (설계서 요약)

- **스토리 6장:** 하산의 길 → 통통 객잔 → 거북 장터 → 쿠비 산채 → 로직 학당 → 무림맹 본단
- **캐릭터·문파:** 캐릭터 10종(기본 3 + 해금 7), 문파 4종(검객·권사·도사·살수), 외형 꾸미기, 환생 전용 3종
- **모드:** 강호행(스토리), 목인항(일일 수련), 투기장(AI 연승), 비무장(비동기 대전), 천하제일 무도회(주말 실시간 토너먼트), 강호유랑(주간 탐험), 폐관수련동(끝판), 환골탈태(환생)
- **날씨·지물:** 밤비·강풍·혹한, 대나무 새총·큰 징

## 8. 기술 구성

- **앱:** Flutter + Flame + Forge2D(Box2D v3 바인딩)
- **서버:** Dart(앱과 같은 물리 코드로 서버가 판정을 다시 계산), AWS 서울
- **동시 접속 1,000명 목표**
  - [실측] 한 수 계산 95%가 2.39ms → 1,000명이 모두 실시간 대전을 해도 CPU 0.1코어 수준
  - 부하 시험 기준: 1,200명 30분, 한 수 왕복 95% 300ms 이하, 서버 1대가 꺼져도 대전이 이어질 것
