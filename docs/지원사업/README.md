# 지원사업 공고 추적표 — 탄지 무림(알까기)

- 목적: 게임 제작·테스트·홍보에 쓸 수 있는 지원사업을 **놓치지 않고** 신청하기
- 짝 문서:
  - 신청서에 공통으로 들어가는 내용 → [`신청서_재료.md`](신청서_재료.md)
  - 할 일 순서 → [`../구현_체크리스트.md`](../구현_체크리스트.md) 「S단계 — 지원 신청」
- 표시: **[확인]** = 기사·공식 자료로 확인한 사실 · **[예상]** = 2026년 실적으로 짐작한 것. 공고가 나오면 공고문 값으로 바꾼다.
- 마지막 갱신: 2026-10-06

## 1. 놓치지 않는 방법

1. **매주 월요일 자동 점검:** 루틴 「알까기 지원사업 공고 점검」이 아래 표의 사업을 검색한다.
   - 새 공고나 날짜가 바뀐 것이 있으면 이 문서를 고치는 PR을 올리고 알림을 보낸다.
2. **공고가 뜨면 3일 안에** 공고문 원문을 받아 아래 3가지를 표에 채운다.
   - 자격 조건(특히 법인 형태)
   - 제출 서류
   - 마감 시각(날짜·시각까지)
3. **마감 2주 전**까지 `신청서_재료.md`로 신청서 초안을 끝내고, **마감 3일 전**에 제출한다(마감 당일은 접수 시스템이 몰린다).
4. 결과(선정·탈락·평가 의견)는 맨 아래 「신청 기록」에 남긴다. 다음 해 신청서를 고칠 때 쓴다.

### 우리에게 맞는 정도 (형 판단용)
- **1순위:** 콘텐츠진흥원 일반형(모바일), 경기게임제작지원, 창구 프로그램
  - 금액이 크거나 수익화 지원이 직접적이다.
- **검토:** 기능성게임 트랙
  - 알까기는 손가락으로 돌을 튕기는 놀이라, 어르신 손 운동·인지 훈련 같은 요소를 넣으면 해당될 수 있다.
  - 지금 설계서에는 없는 방향이라 **넣을지는 형이 결정**한다.
- **테스트·홍보:** 플레이엑스포 FGT, BIC, 인디크래프트, GIGDC
- **해당 없음(현재):** AI 트랙 — 게임에 AI 기능이 없다.

## 4. 신청 전에 꼭 확인할 것

| 확인할 것 | 왜 | 상태 |
|---|---|---|
| **어느 법인으로 신청하나** (사협 / 로지스 / 새 법인) | 콘텐츠진흥원 일반형 대상은 "중소기업"이다. **사회적협동조합이 해당되는지 확인하지 못했다.** | ⏳ 공고문 자격 조항 확인 또는 콘텐츠진흥원 문의 |
| 경기도 소재 여부 | 경기게임제작지원은 경기도 게임기업 대상 | ⏳ 신청 법인 주소로 확인 |
| e나라도움 가입·인증서 | 콘텐츠진흥원 접수 창구 | ⏳ |
| 게임 개발 경험 증빙 | 일반형 자격: "개발 경험이 있거나 개발할 능력이 있는" 기업 | 시연 빌드·영상으로 준비 (S-04·S-05) |
