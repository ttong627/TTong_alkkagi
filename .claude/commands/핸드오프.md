# /핸드오프 — 긴 대화 저장 → 새 세션 이어가기 (도나)

**발동**: 형이 "핸드오프"·"저장하고 이어가", 또는 컨텍스트 50% 도달 시 `/작업` 체인이 권유.
**목적**: 긴 대화의 맥락을 잃지 않도록 **현재 상태를 1장으로 저장** → 새 프롬프트에서 바로 이어받는다.

## 저장 (HANDOFF.md 작성)
프로젝트 루트에 `HANDOFF.md`를 생성/갱신한다. 갱신시각은 `date '+%Y-%m-%d %H:%M'`.
포함 항목(간결·실행가능):
1. **지금 하는 일**: 한 줄 목표 + 어느 단계까지 왔나(/작업 체인이면 몇 단계).
2. **완료**: 이번 세션에서 끝낸 것(파일·커밋 해시 포함).
3. **미완·다음 단계**: 바로 이어서 할 일(순서대로). 막힌 지점·대기 중 결정.
4. **열린 결정**: 형 답을 기다리는 선택지.
5. **검증 상태**: 테스트/빌드 마지막 결과, 미커밋 변경 여부(`git status -s`).
6. **참고**: 관련 파일 경로·PROJECT_STATUS·메모리 포인터.

```markdown
# 🔁 HANDOFF — <repo> (<YYYY-MM-DD HH:MM>)
## 지금 하는 일
- <목표> · 현재 <단계/진행률>
## 완료
- <항목> (<파일/커밋>)
## 다음 단계 (이어서 할 일)
1. <...>
## 열린 결정
- <...>
## 검증 상태
- 테스트 <결과> · 빌드 <결과> · 미커밋 <git status 요약>
## 참고
- <파일/PROJECT_STATUS/메모리>
```

저장 후 형에게:
> 💾 HANDOFF.md 저장 완료. **새 세션을 열고 "이어서"** 라고 하시면 여기서부터 계속합니다.

## 복원 (새 세션에서 "이어서")
- 새 세션에서 형이 "이어서"·"계속"이라고 하면: 루트 `HANDOFF.md`(+ `PROJECT_STATUS.md` + 자동메모리)를 읽고, **다음 단계부터 즉시 재개**한다. 끝났으면 HANDOFF.md는 정리.

## 핵심
- 길어지면 미루지 말고 저장(컨텍스트 50% 규칙). 새 세션 = HANDOFF.md 읽고 다음 단계부터. 하니스 자동요약과 병행해 이중 안전.
