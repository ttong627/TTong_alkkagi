# /스킬검증 — 스킬 설치 전 보안 스캔 (코코)

**발동**: 형이 "스킬검증", "이 스킬 안전해?", 새 스킬/플러그인 설치 직전.
**목적**: 써드파티 스킬은 **암묵적 신뢰로 실행**된다(연구상 26.1% 취약·5.2% 악성). 설치 **전** 반드시 스캔한다.

## 사전 조건
- Docker Desktop 실행 + 이미지 `skillspector:latest` (빌드됨). 없으면:
  ```bash
  cd I:/ttong_project/_agent-skills-staging/SkillSpector && docker build -t skillspector .
  ```
  (재클론: `git clone --depth 1 https://github.com/NVIDIA/SkillSpector.git`)

## 실행
- **로컬 폴더/파일**(현재 디렉토리 마운트):
  ```bash
  MSYS_NO_PATHCONV=1 docker run --rm -v "$PWD:/scan" skillspector scan /scan/<대상> --no-llm
  ```
- **깃허브 URL 직접**:
  ```bash
  MSYS_NO_PATHCONV=1 docker run --rm skillspector scan https://github.com/<owner>/<repo> --no-llm
  ```
- LLM 의미분석까지(선택): `--no-llm` 제거 + `.env`에 `SKILLSPECTOR_PROVIDER=anthropic` 등 키.
- 리포트 포맷: 기본 터미널 / `--format json|markdown|sarif`.

## 판정 원칙 (드림팀)
- 스캐너는 **보수적**이다 — 단독 신뢰 금지. 점수만 보지 말고 **각 finding의 Location 실제 라인을 직접 확인**한다.
- 흔한 **오탐**: "Never commit secrets"(보안 지침인데 PE3로 오탐), 방법론 스킬의 EA1/EA2(자율성) 경고, 정상 도구의 subprocess(AST4).
- **진짜 위험 신호**: 외부 URL로 데이터 전송(curl/POST), `ANTHROPIC_API_KEY`/`~/.ssh`/`.aws` 읽어 전송, base64/`-EncodedCommand` 난독화, `rm -rf`·자동 파괴 명령, 지시문 내 숨은 프롬프트 인젝션.
- **공급망**: 스킬이 PyPI/npm 패키지 설치를 요구하면 패키지 진위(저자·project_urls가 원 리포와 일치, 타이포스쿼트 여부)를 `curl pypi.org/pypi/<pkg>/json`로 확인.
