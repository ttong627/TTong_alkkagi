# /연출 — 연출 재연출 + 평가 (연출 드림팀)

**발동**: 형이 "연출" / "재연출" / "N화 진입부 재연출하고 평가해줘"라고 하면 즉시.
**목적**: 형이 매번 설명하지 않아도, 지정한 화·구간을 **연출 평가지 SSOT로 진단→재연출→채점**해서 리포트 1장으로 낸다.
**대상 기본값**: 인자가 없으면 **《죽기 전에 한 끼》 1화 진입부(도입~식당 진입, 대략 CUT1~46)**.

## 절대 원칙 (위반 금지)
- **이미지 생성 금지**: 이 스킬은 **연출 콘티(텍스트)와 평가 리포트까지만** 낸다. 실제 컷 이미지 재생성은 형의 별도 승인 후 `webtoon_gen.py`로. ("모든 제작 중지" 상시 제약 존중 — 대사 뷰어·텍스트 산출물만.)
- **평가지 SSOT 준수**: 채점은 반드시 `연출_평가지.md`의 A·B·C·D 항목으로. 임의 기준 금지.
- **만드는 팀 ≠ 까는 팀**: 감독안을 낸 뒤 반드시 비평 진영이 독립적으로 깐다(자기 검수 금지).
- **외과적**: 요청한 구간만 손댄다. 정상 구간을 되돌리는 퇴행 금지.
- **근거 필수**: "늘어짐"이라 하면 반드시 컷 번호·이유를 댄다(추측 금지).

2. `Projects/webtoon/죽기전에한끼/docs/캐릭터시트_규칙.md` — **회차 출연진 시트 규칙(0단계 게이트)**
3. `Projects/webtoon/죽기전에한끼/작품바이블.md` — 톤·캐릭터·§7 흐름·§8 연출핵심·§9 절대규칙
4. `Projects/webtoon/죽기전에한끼/N화_제작시트.md` — 대상 화의 현재 컷 구성(컷번호·등장·프롬프트·대사)

## 연출 드림팀 (역할)
- **감독 노아**: 톤·긴장 곡선·클라이맥스 설계. 재연출 콘티 총괄.
- **PD 리사**: 페이싱·컷 수·완급 리듬(A4). 늘어짐 압축.
- **조연출 케인**: 카메라·앵글·컷 크기(A3). 시각 리듬.
- **비평 편집장 / 독자대변**: 냉정하게 깐다 — 늘어짐·뻘쭘·훅부재·"무슨 말인지 모름"(C1·C2·C6).
- (안토니 조율 · 미연 QA 게이트 · 찰리 과잉연출 리스크 점검)

## 실행 절차

### 0단계 — 캐릭터 시트 게이트 [홀리·미아] ★시트 없으면 연출 시작 불가
- `docs/캐릭터시트_규칙.md`에 따라 **그 화 출연 전원 시트 존재 확인**.
- **회차 주인공 손님**(지연·창수·민우 등): `02_캐릭터시트/<이름>_시트.png` + 결착 단일본 `00_Assets/character/2D/<이름>.png` 존재? **없으면 먼저 생성**(화풍_clean 결착, aspect 4:3, 텍스트 없음, 의상 고정)하고 저장 후 진행.
- **고정 캐릭터**(끝순·뽀글이·만복): 기존 시트 보유 → 재사용(신규 제작 불필요).
- 익명 군중은 시트 불필요. 시트 미비 캐릭터가 남아 있으면 여기서 멈추고 시트부터.

### 1단계 — 대상 확정 [안토니]
- 인자에서 **작품·화·컷 구간**을 파싱. 없으면 기본값(죽기전에한끼 1화 진입부 CUT1~46).
- 해당 제작시트에서 대상 컷의 (컷번호·장면·등장·대사) 목록을 읽어 표로 요약.

### 2단계 — 현행 진단 (비평 진영이 먼저 깐다) [편집장·독자대변]
- 평가지 **C 게이트(C1~C6)** 를 컷별로 훑어 위반을 **컷번호+근거**로 나열.
  - C1 늘어짐: 같은 의미 컷 5연속? / C2 뻘쭘: 맥락없는 등장? / C6: 5컷 안에 "무엇을 전개 중"인지 한 줄 설명 가능?
- 평가지 **A(재미 5축)** 을 현행 기준 점수화(왜 그 점수인지 1줄 근거).

### 3단계 — 재연출 콘티 (감독안) [노아·리사·케인]
- 진단을 바탕으로 **새 컷 구성**을 제안. 원본 대비 압축/재배치/추가를 명시.
- 각 새 컷: **연출 의도 · 컷 크기(대/중/소) · 카메라 앵글 · 완급(느림/빠름)** 를 적는다.
- 훅(A2 정보 지연) 을 진입부에 최소 1개 심는다. 클라이맥스 컷은 대형(A1·A3).

### 4단계 — 재채점 + 리스크 [미연·찰리]
- 재연출안을 평가지로 **다시 채점**(A/25 + B/15 = /40, 게이트 통과 __/6, 등급 S/A/B/C).
- 찰리: 과잉 연출·개성 훼손·컷 급증 리스크 1줄 경고(있으면).

### 5단계 — 리포트 출력 (평가지 양식 그대로)
`연출_평가지.md`의 「평가 리포트 양식」 블록 형식으로 출력한다:
```
[연출 평가] N화 <구간>
■ 점수  A __/25  B __/15 = 총 __/40 · 등급 [..]   (재연출 전 → 후)
■ 게이트  통과 __/6  ⚠️ 걸린 항목
■ 진단(비평 진영)  - [늘어짐] CUT..: 근거 → 처방  ...
■ 재연출 콘티(감독안)  기존 N컷 → 제안 M컷  | 새컷 | 원본 | 의도 | 크기 | 완급 |
■ 다음 행동: 형 승인 대기 / 반영할 컷 목록
```

### 6단계 — 반영 (형 승인 시에만)
- 형이 "반영해"라고 하면 → 해당 화 **제작시트(.md)의 컷 표만 외과적으로 수정**(장면·프롬프트·순서). 이미지 재생성은 여전히 형의 별도 지시로 `webtoon_gen.py` 실행.
- 반영 후 변경 컷 목록과 파일 경로를 형에게 전달(산출물 위치 항상 안내).

## 핵심 원칙 (재확인)
- 평가는 재미를 만드는 게 아니라 **재미를 죽이는 실수를 걸러낸다.**
- **게이트는 무관용**(반복 문제 재발 0), A·B는 방향 제시, **최종 재미 판단은 형**.
- 텍스트 콘티·리포트까지만 — **이미지 생성은 형 승인 후**.
- 끝 = 재연출 콘티 + 점수 리포트 + "다음 행동" 1줄까지 내야 완료.
