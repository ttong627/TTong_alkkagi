# /루프 — 영플·명단정제·플랫폼 루프 준비

**발동**: `/루프 영플 <할 일>` · `/루프 명단정제 <할 일>` · `/루프 플랫폼 <할 일>` · `/루프 감시 영플|플랫폼`
**하는 일**: 작업 폴더를 찾고 `.loop/PROMPT.md`·`.loop/fix_plan.md`를 만들어, 형이 **한 줄만 붙여넣으면** 완료될 때까지 돌게 한다.
⛔에이전트를 띄우지 않는다. 진행 상황은 짧게 계속 말한다.

## 2. `/루프 <프로그램> <할 일>` 절차
1. 폴더를 고르고 `git status --porcelain` 건수를 알린다(남의 미커밋은 건드리지 않는다)
2. 할 일과 관련된 코드를 grep 으로 찾아 **실제 파일 경로**를 확인한다
3. `.loop/` 가 이미 있으면 `.loop/_이전_<YYYYMMDD_HHMM>/` 로 옮긴다
4. `.loop/PROMPT.md` 를 아래 틀로 만든다(할 일·폴더·검증 명령·프로그램 규칙을 채운다)
5. `.loop/fix_plan.md` — 할 일을 **한 회차에 끝낼 수 있는 칸 3~8개**로 쪼갠다. 칸마다 파일 경로를 적는다
6. 검증 명령을 한 번 돌려 **기준선**(통과 수)을 fix_plan 맨 위에 적는다
7. 커밋되지 않게: 작업 폴더와 지금 창 폴더 각각 `git rev-parse --git-path info/exclude` 파일에 `.loop/` 와 `.claude/ralph-loop.local.md` 줄이 없으면 추가
8. 형에게 **복사할 한 줄**을 상자 하나로 준다 (⛔지시문에 `$`·백틱·큰따옴표·괄호를 넣지 않는다 — 셸이 해석해 깨진다):
   ```
   /ralph-loop "<작업폴더>/.loop/PROMPT.md 를 읽고 그대로 한 회차 진행" --max-iterations 10 --completion-promise "LOOP_END"
   ```
   멈추기: `/cancel-ralph`

### PROMPT.md 틀
```markdown
# 루프 — <프로그램> · <할 일> (시작 <YYYY-MM-DD HH:MM>)

## 작업 폴더
<절대경로> — 모든 명령은 이 폴더에서

## 목표
<할 일>

## 한 회차 = 한 칸
1. .loop/fix_plan.md 에서 [ ] 첫 칸 하나를 고른다
2. 관련 파일을 끝까지 읽고 원인·영향을 확인한 뒤 고친다 (이미 있는 유틸 재사용 · 요청 밖 수정 금지)
3. 검증: <검증 명령>
4. 그 칸 옆에 결과를 적는다 — 성공 `[x] … → 620/620 · build OK` / 실패 `[ ] … (실패 1회: 원인 한 줄)`
5. 한 줄 보고: `[회차 n] 무엇을 고침 → 검증 결과 · 다음 칸`

## 멈춤 규칙
- 같은 칸이 2번 실패 → fix_plan 맨 위에 `⛔막힘: 칸 · 원인 · 시도한 것 · 제안` 을 적는다
- 기준선보다 통과 수가 줄면(퇴행) 그 회차 수정을 되돌리고 실패 1회로 센다

## 종료 신호
아래 둘 중 하나가 **참일 때만** <promise>LOOP_END</promise> 를 출력한다
(a) 모든 칸 [x] 이고 검증 명령이 전부 통과  (b) ⛔막힘을 기록했다

## 금지
배포 · 운영 데이터 쓰기·삭제 · git push(커밋까지만) · 에이전트 호출 · 개인정보(이름·주소·전화) 출력·커밋

## 프로그램 규칙
<아래 해당 프로그램 규칙을 붙인다>
```

### 프로그램 규칙
- **영플**: 메모리 `yyplus_INDEX.md` 규칙(배송·패키지·단가·정렬·보건소별) 먼저 · 새 의존성 금지 · 버그는 호출처 전부 찾아 공유 함수 한 곳 · 끝 칸에 `src/version.js`·`CHANGELOG.md` 갱신
- **명단정제**: 주소 규칙은 공유 코어(`services/address-service/src/shared/`) 한 곳 · 조립→파싱→재조립 3회 결과 같아야(멱등) · 오적용 차단 케이스를 같이 추가 · 정규식 선택 꼬리(`?`)는 낱말을 먹는다 → 내용어 과잉차단 케이스 필수 · 테스트엔 **가짜 주소만** · 명단 결과는 집계 숫자로만
- **플랫폼**: wslos.kr 은 앱 하나(별도 배포 단위 신설 금지) · 옮기거나 붙이면 구성 테스트 기대값을 **먼저** 추가 · 계정·데이터·auth 병합·삭제 금지 · GitHub 리포 없음(로컬 커밋만)

## 3. `/루프 감시 <영플|플랫폼>` — 내장 /loop 한 줄
- 영플: `/loop 10m http://34.50.53.232 이 HTTP 200 인지 확인하고 이상하면 바로 알려줘. 3번 연속 정상이면 루프 멈춰`
- 플랫폼: `/loop 10m https://wslos.kr 이 HTTP 200 인지 확인하고 이상하면 바로 알려줘. 3번 연속 정상이면 루프 멈춰`
- 확인은 `curl -s -o /dev/null -w "%{http_code}" --max-time 15 <주소>` 한 번. ⛔배포·재시작은 하지 않는다(형 확인)
