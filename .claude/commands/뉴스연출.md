# /뉴스연출 — 뉴스 대본·구성 점검 + 사실 대조 + 대책 (뉴스 드림팀)

**발동**: 형이 "뉴스연출" / "뉴스 점검" / "제N보 점검해" 라고 하면 즉시.
**목적**: 만든 사람이 못 보는 것을 **다른 눈으로 잡아낸다.**
  뉴스는 재미보다 **① 사실이 맞는가 ② 뜻이 전달되는가**가 먼저다. 이 둘을 숫자로 판정한다.
**대상 기본값**: 인자가 없으면 **가장 최근 회차의 대본과 조립본**.

## 절대 원칙 (위반 금지)
- **사실이 최우선**. 재미·구성보다 앞선다. 확인 안 된 숫자·날짜·인용이 하나라도 있으면 **그 회차는 통과 못 한다.**
- **자료대장 대조 필수**: 날짜·인물·제도 사실은 `Projects/channel_jahwal/_앵커생각_자료대장.md` 와 대조한다.
  대장에 없으면 → 출처를 찾아 대장에 먼저 올리고, 못 찾으면 **그 문장을 뺀다.**
- **만드는 팀 ≠ 까는 팀**: 대본을 쓴 쪽이 스스로 채점하지 않는다. 비평 진영이 독립적으로 깐다.
- **영상 생성 금지**: 이 스킬은 **대본·구성 진단과 대책까지만.** 재제작은 형 승인 후.
- **추측 금지**: "늘어진다"고 하면 **몇 번째 문장, 몇 초**인지 댄다.
- **외과적**: 지적한 곳만 고친다. 멀쩡한 데를 되돌리는 퇴행 금지.

## 뉴스 드림팀 (역할)
- **보도국장 한서진**: 전체 편집 방향·소식 배열·시간 배분. 최종 조율.
- **팩트체커 노민": 숫자·날짜·인용·조항을 **원문과 한 줄씩** 대조. 사실 아니면 여기서 멈춘다.
- **데스크 강우재**: 문장이 한 번에 들리는가. 어려운 말·이중부정·긴 수식을 잡는다.
- **시청자대변 이든**: "이게 나랑 무슨 상관인데?" 를 대신 묻는다. 남 얘기로 들리면 지적.
- **연출 서다인**: 화면과 말이 맞물리는가. 자료화면이 말을 돕는가 방해하는가.
- (안토니 조율 · 미연 QA 게이트 · 하나 자활 제도 검증)

## 실행 절차

### 0단계 — 사실 게이트 [팩트체커] ★여기서 막히면 다음 단계 없음
대본에서 **숫자·날짜·고유명사·인용·법조항**을 전부 뽑아 표로 만든다. 각각에 대해:
- 자료대장에 **있는가** → 출처 링크와 함께 ✔
- 없는가 → 원문(보도자료·법령·기사)을 찾아 확인 → 대장에 추가
- 못 찾는가 → **★미확인** 표시. 그 문장은 **삭제 또는 표현 완화**(단정 금지)

출력: `사실 N건 · 확인 N건 · 미확인 N건`. **미확인이 1건이라도 있으면 이 회차는 보류.**

### 1단계 — 구성 점검 [보도국장]
- 소식 배열: 큰 것이 앞에 있는가. 비슷한 소식이 붙어 지루하지 않은가
- 시간 배분: 한 소식이 전체의 25%를 넘지 않는가
- 「앵커 생각」이 **4단 규격**(①걸이 ②겹침 ③비틀기 ④여운, 60~100초)을 지켰는가
- 제1보~직전 회차와 **중복 소재**가 없는가 (있으면 재방송이다)

### 2단계 — 전달력 점검 [데스크·시청자대변]
문장 단위로 훑어 아래를 **문장 번호와 함께** 지적한다.
- **한 번에 안 들리는 문장**: 25자 초과 + 수식 2개 이상 / 이중부정 / 피동 남발
- **어려운 말**: 지침 용어를 그대로 옮긴 것("보장기관은", "인정취소" 등) → 풀어 쓸 것 제안
- **남 얘기**: 그 소식이 시청자에게 무엇인지 한 줄로 말할 수 있는가. 못 하면 지적
- **숫자 과다**: 한 소식에 숫자 4개 넘으면 귀가 못 따라간다

### 3단계 — 화면 점검 [연출]
- 말과 화면이 **어긋난 자리**(문장 번호 + 자료화면 이름)
- 앵커가 보이는데 **입이 안 움직이는 자리** (`_place_why.py` 배치표로 확인)
- 그래픽이 자막 바를 침범하는지 (y 1434 아래 금지)
- 「앵커 생각」에 그래픽이 2장 넘게 들어갔는지 (규격 위반 — 설명이 된다)

### 4단계 — 채점
```
사실   __/40   (미확인 1건당 -10, 오류 1건당 -20)
구성   __/20   (배열·시간배분·중복·4단규격)
전달   __/25   (안 들리는 문장 1개당 -3)
화면   __/15   (어긋난 자리 1개당 -3)
────────────────
총점   __/100    S 90+ · A 80+ · B 70+ · C 70미만(재작업)
```

### 5단계 — 대책 (이 스킬의 핵심)
지적마다 **고칠 문장을 실제로 써서** 낸다. "줄여라"가 아니라 **줄인 문장**을 낸다.

```
[대책] a8 문장11
  지금  할 수 있음은 안 해도 그만이라는 뜻입니다.  (28자·이중부정)
  대안  할 수 있음은, 안 해도 된다는 뜻입니다.      (20자)
  이유  '그만이라는'이 귀에 안 걸린다. TTS 도 뭉갠다(실측 88%)
```

### 6단계 — 리포트 출력
```
[뉴스 점검] 제N보
■ 사실  확인 __건 / 미확인 __건    ← 미확인 있으면 여기서 STOP
■ 점수  사실 __/40 구성 __/20 전달 __/25 화면 __/15 = __/100 [등급]
■ 지적  · [사실] ...  · [전달] a8 문장11 ...  · [화면] ...
■ 대책  (고칠 문장 전문)
■ 다음 행동: 형 승인 대기 / 반영할 목록
```

### 7단계 — 반영 (형 승인 시에만)
형이 "반영해"라고 하면 → `_news01b_narration.py` 의 `SCRIPT` 와 `SHOTS` 를 **외과적으로 수정**.
수정 후 반드시 `python _narr_audit.py --fix` 로 발음 재검사까지 돌린다(대본이 바뀌면 음성도 다시 뽑아야 한다).

## 핵심 원칙 (재확인)
- **사실이 틀리면 나머지는 볼 필요도 없다.** 0단계가 게이트인 이유다.
- 점검은 잘 만드는 게 아니라 **잘못 나가는 걸 막는다.**
- 지적은 반드시 **문장 번호·초·근거**와 함께. 없으면 그 지적은 무효다.
- 대책은 **쓸 수 있는 문장**으로 낸다. 방향만 말하면 형이 또 일해야 한다.
- 끝 = 점수 리포트 + 고친 문장 전문 + "다음 행동" 한 줄까지 내야 완료.
