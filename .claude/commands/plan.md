# /plan — 계획 세우고 바로 진행 (2026-09-27 형 규칙으로 다시 씀)

> 옛 판은 「계획을 보여주고 형이 yes 할 때까지 코드 금지」였다. 형 규칙(golden-principles #9 · CLAUDE.md §1)은
> **계획을 한 줄씩 밝히고 기다리지 않고 진행**, 되돌릴 수 없는 일(운영 배포·삭제·결제·외부 발송)만 먼저 묻는 것이다.

## 절차

1. **이해 먼저** — 고칠 파일과 실제 흐름을 끝까지 읽는다. 가정은 한 줄로 밝힌다. 이미 있는 코드·스크립트를 먼저 찾는다(재사용 사다리: 만들 필요? → 이미 있나 → 표준 라이브러리 → 설치된 의존성 → 최소 코드).
2. **계획 쓰기** — 단계마다 확인 방법을 붙인다.
   ```
   목표: <한 줄>
   1. <단계> → 확인: <명령/결과>
   2. <단계> → 확인: <명령/결과>
   위험: <되돌릴 수 없는 것·데이터 손실 가능성 — 없으면 「없음」>
   ```
3. **바로 진행** — 계획을 형에게 보여 준 뒤 기다리지 않고 1단계부터 한다. 위험 칸에 되돌릴 수 없는 일이 있으면 **그 단계 직전에만** 형에게 묻는다.
4. **저장** — 프로젝트 루트에 `prompt_plan.md` 가 있으면 계획을 맨 위에 기록하고 옛 계획은 「## 이전 계획」 아래로 내린다(다음 세션 `/sync` 가 읽는다).
5. **완료** — 각 단계의 확인 명령을 이번에 돌린 결과(통과 수·exit 0)로 보고한다.

## 에이전트

기본은 안토니가 직접 계획한다. 형이 「플래너 써」라고 하거나 서로 독립인 큰 덩어리일 때만 `planner` 에이전트를 부른다.
