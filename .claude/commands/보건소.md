# /보건소 — 보건소 전담 비서 (형 지시 2026-09-08 · 2단계)

**발동**: `/보건소 영통 점검` · `/보건소 c_003 청구서 --month 2026-08 --actual grand=4617860` · `/보건소`(인자 없음 = 16곳 현황).
**목적**: 보건소 하나의 일을 **그 보건소 비서**가 맡게 한다 — 규칙(clinicRules)·발주서·청구서 세 서랍을 섞지 않고, 매달 세 게이트에서 실행 근거 있는 PASS/FAIL 만 낸다.

## 절대 원칙
- **읽기만**: 비서는 운영 데이터·규칙을 쓰지 않는다. 고칠 것은 목록으로 형에게 → 「그래」 → 안토니가 DRY→APPLY.
- **추측 금지**: 실물 숫자는 실물 청구서에서 읽은 값만 `--actual` 에 넣는다. 없으면 NO_ACTUAL 로 남긴다(숫자를 지어내지 않는다).
- **매칭·단가는 담당자가 정한다**: 어긋남은 표시만(「등록≠계약」).
- **PII 무반출**: 인원수·금액·규칙 요약만.
- **자기 보건소만**: 다른 보건소 값은 올리지 않는다(가로로 보는 것은 총괄 · 3단계).

## 실행 절차

### 0. 인자 풀기
`$ARGUMENTS` 첫 낱말 = 보건소(이름 「영통」·「영통구」·「영통보건소」·cid `c_003` 어느 것이든). 둘째 = 명령(기본 `점검`). `--month`(기본: 청구서=지난달 · 발주서=이달) · `--actual`.
슬러그 표: 오산 osan · 과천 gwacheon · 영통 yeongtong · 팔달 paldal · 권선 gwonseon · 장안 jangan · 가평 gapyeong · 처인 cheoin · 수지 suji · 기흥 giheung · 광주 gwangju · 김포 gimpo · 부천 bucheon · 의정부 uijeongbu · 남양주 namyangju · 광명 gwangmyeong → 에이전트 이름 `hc-<slug>`.

### 1. 인자 없음 — 16곳 한 줄 현황 (LLM 없이 CLI 만)
```bash
cd i:/ttong_project/yyplus/wssc-unified && source ~/.wssc-secrets/env.sh && for c in c_001 c_002 c_003 c_004 c_005 c_006 c_007 c_008 c_009 c_010 c_011 c_012 c_013 c_014 c_015 c_016; do node server/clinic-agent.mjs $c dossier --md --month <지난달> | grep -E "^# |총 청구금액|G3|^\- ⚠|^\- \[20|^### (🆕|🔁|✅)|^\- (🆕|🔁|✅) " | head -24; done
```
보건소마다 「총 청구금액 · G3 판정 · 경고 · 확인요청(🆕 새로 N · 🔁 계속 N · ✅ 풀림 N)」 한 줄로 묶어 표로 낸다. ⚠확인요청은 v5.184 부터 `### 🆕/🔁/✅` 묶음 줄로 나온다 — 필터가 옛 `- [20…` 만 보면 0건으로 보인다(제시 2026-09-13). 상태판이 없는 곳은 「아직 안 돌았다」.

### 2. 보건소 하나 — 그 비서를 부른다
Agent 도구 `subagent_type: hc-<slug>` 로 호출하고 지시문은 **그대로** 넘긴다:
- `점검` → 「점검」. 기준월 두 장(이달=발주 축 · 지난달=청구 축). 비서 파일 「일하는 순서」 2.
- `발주서` → 「발주서」 + `--month`. 순서 4(시트 지도 → 인원 → 분유 → 계약 매칭 → 문의 문구).
- `청구서` → 「청구서」 + `--month` + `--actual …`. 순서 3(g3 → PASS/FAIL → 원인 후보 ≤3 → 「등록≠계약」 행 → 엑셀 원본 요청).
비서가 낸 보고를 **그대로** 형에게 전한다(요약해 묻어두지 않는다). 비서가 「고칠 칸 목록」을 내면 그 목록을 형 결정 자리로 올린다.

### 3. 실측 근거 없는 PASS 는 없다
비서 보고에 실행 명령·출력이 없으면 되돌려 보낸다(「어느 명령을 돌렸고 무엇이 나왔나」).
