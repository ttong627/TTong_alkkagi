# /보건소총괄 — 보건소 총괄 비서 (대화용 한글 이름)

이 명령은 **`/hc-manager` 와 같은 절차**다. `~/.claude/commands/hc-manager.md` 를 읽고 인자(`$ARGUMENTS`)를 그대로 넘겨 그 절차를 따른다.

- 스케줄러가 영문 이름을 쓰는 이유: `claude -p` 에서 한글 명령 이름은 공식 문서에 없고, `claude.cmd` 배치 파일을 거치며 한글 인자가 깨질 수 있다(2026-09-15 확인).
- 대화에서 형이 부르면 먼저 `--dry` 로 보여 드리고, 형이 「써」 하면 인자 없이 한 번 더 실행한다.
