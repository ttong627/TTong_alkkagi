# /검사 — 독립 정밀 검사 (드림팀 검사단)

**발동**: 형이 "검사"·"검사해"라고 할 때만. ⛔다른 스킬이 자동으로 부르지 않는다(2026-09-14 형 지시).
**목적**: 작업을 **수행하지 않은** 검사단이 **신선한 시각**으로, 의도대로 됐는지·보충할 점·트리거·오류가 없는지 정밀검사한다.

## 절대 원칙 (검사의 생명 = 독립성)
- **편향 차단**: 메인 세션의 구현 과정·자기합리화를 검사 근거로 삼지 않는다. **원 지시(의도) + 결과물(diff/산출물)만** 본다.
- **반증 자세(adversarial)**: 통과시키려 하지 말고 **깨뜨리려** 한다. "이게 진짜 의도대로인가? 빠진 건? 깨지는 입력은?"
- **증거 기반**: 모든 지적은 **파일:라인** 또는 실행 결과로. 일반론·추측 금지.
- **외과적**: 검사는 수정하지 않는다(보고만). 수정은 형 승인 후 본 세션에서.

## 실행 절차

### 1단계 — 의도·결과 캡처
```bash
git diff --stat 2>/dev/null; echo '---'; git diff 2>/dev/null | head -400
git log -3 --oneline 2>/dev/null
```
- **의도**: 인자로 받은 "원래 지시"를 한 줄로 명문화(없으면 직전 대화의 요구를 요약). "무엇을, 왜 의도했나".
- **결과**: 변경 diff·신규 산출물. UI 변경 포함 여부 판단(디자인 검사 투입 결정).

### 2단계 — 독립 검사단 4종 **병렬 투입** (한 메시지에서 Agent 4회 호출)
`Agent` 도구를 **같은 응답에서 4번**(subagent_type="general-purpose") 호출해 fresh context로 동시 검사. 각 에이전트엔 **의도 + diff/대상 경로**만 주고, 본 세션의 추론은 넘기지 않는다. (UI 변경 없으면 ④ 디자인 생략 → 3종.)

각 검사관 공통 지시:
> "당신은 이 작업에 **참여하지 않은 독립 검사관**입니다. 아래 [의도]와 [결과물]만 보고, 통과시키려 하지 말고 **반증**하세요. 발견을 ✅이상없음 / ⚠️보충필요 / 🚨오류 로 분류하고 **파일:라인**과 근거를 명시하세요. 필요시 실제 파일을 읽어 확인하세요."

- **① 기능·의도 정합 [미연·안토니]**: 의도대로 동작하나? 미충족·누락 요구, 빠진 트리거/진입점, 엣지케이스(빈값·대용량·동시성·오류경로), 회귀 가능성.
- **② 코드·오류·무결성 [미아·브루마]**: 버그·런타임 오류, 찌꺼기·중복·죽은 코드, 에러핸들링 누락, 불변성 위반, 의존성·타입 문제.
- **③ 보안 [코코]**: 하드코딩 시크릿, 입력 검증, 주입/XSS/CSRF, 인증·권한, 민감정보 노출, 레이트리밋.
- **④ 디자인·UX [홀리]** (UI 변경 시만): 디자인 토큰(06b 따뜻 톤) 준수, 일관성, 접근성, 반응형, 로딩·빈상태·에러 피드백.

### 3단계 — 안토니 통합 판정
검사단 결과를 종합해 중복 통합·우선순위화.
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔎 독립 검사 보고 — 의도: <한 줄>
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 판정: [PASS · 보충필요 · FAIL]

🚨 오류 — 배포 전 반드시 수정
  1. [제목] 담당:[검사관] 위치:파일:라인 / 문제 / 해결책
⚠️ 보충 — 함께 처리 권장
  2. ...
✅ 이상 없음
  - 의도 충족 / 정상 확인 항목
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
- **판정 기준**: 🚨 1개↑ → **FAIL** / 🚨 0·⚠️ 1개↑ → **보충필요** / 둘 다 0 → **PASS**.

### 4단계 — 후속
- 단독 호출 시: 보고 후 "수정 항목 번호를 주시면 본 세션에서 처리합니다"로 멈춤(형 승인 전 수정 금지).
- `/작업` 체인 호출 시: 판정을 체인으로 반환(PASS면 진행, FAIL/보충필요면 수정 루프).

## 핵심
- 검사관은 **fresh context**(독립) · **반증** 자세 · **파일:라인 증거** · **수정은 보고만**.
