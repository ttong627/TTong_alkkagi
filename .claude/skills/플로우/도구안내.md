# Flow 도구 안내 — 34종 (2026-09-15 형 계정 · 프로젝트 → 도구 실측)

> 비유: 프롬프트 칸이 **망치**라면 도구는 Flow 안의 **전용 공구**(각도자·스케치판·이어붙이기 틀).
> 여는 곳: 프로젝트 → 왼쪽 「도구」 → 도구 살펴보기. **즐겨찾기** = 모든 프로젝트 · **고정(Pin)** = 이 프로젝트만 ([공식 도움말](https://support.google.com/flow/answer/17104535)).
> 도구로 만드는 것도 크레딧을 쓴다 — **생성 버튼은 형이 누른다**.
> ⚠️설명은 갤러리 한 줄 설명 + 공개 자료 기준. 도구 안 입력 칸은 **처음 쓸 때 확인**(아직 하나씩 열어 보지 않았다).
> ⚠️「커뮤니티·템플릿·내 도구」 탭은 눌러도 같은 목록이 읽혀 내용을 확인하지 못했다.

## 레시피

### A. 멀티샷 — 한 장면을 여러 컷으로
1. 기준 장면 그림 1장(@배경 + @캐릭터)
2. **Shot Explorer** 로 와이드·미디엄·클로즈업 2~3각도 — 또는 **Grid Architect** 로 2×2 격자 한 장을 만들고 칸별로 뽑기
3. 뽑은 그림 = 컷별 첫 프레임 → `04_장면/S01a.txt`·`S01b.txt` … Omni Flash 1.1 · Video Frames
4. **Stringout Creator** 로 이어 보고, 흔들린 컷은 `flow_similarity.py`
- ⚠️검색 요약에 「카메라 시퀀스를 한 번에 만드는 멀티샷」이 나오지만 **공식 도움말에서 확인하지 못했다** → 확인 전까지는 격자·각도 방식

### B. 스케치 → 그림 → 영상
형 낙서(구도·포즈) → **Simple Sketch**(화풍 = Style Writer 문구) → 첫 프레임 → 영상
- 입력 스케치는 **구도·앵글·원근·포즈·배치의 설계도**로만 쓰인다(공개 사용 예) — 선을 그대로 따르지 않는다

### C. 조립·분해 (3D)
블렌더/CAD 로 분해 프레임 렌더 → **3D Model Visualizer** 또는 첫·끝 프레임으로 화풍 입히기
→ 분해 전 = 첫 프레임 · 분해 끝 = 끝 프레임으로 Omni 영상
- ⚠️AI 영상은 **부품 수·순서를 못 센다** → 조립 순서의 정본은 블렌더 렌더 (메모리 `reference_3d_assembly_video_skills_0915`)
