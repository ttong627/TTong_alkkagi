# Storyboard Director — 프리미엄 영상 스토리보드

영상 한 편을 **세계관**과 **초 단위 타임라인**으로 설계해 마크다운 표 스토리보드로 출력한다.
광고·뮤비·단편·브랜드필름·다큐·소셜클립 등 장르 불문, 시간 순으로 촬영/편집 바로 들어갈 수 있는 수준의 디테일을 만든다.

이 스킬은 **스토리보드 설계 전용**이다. 영상 생성 프롬프트(예: Seedance/Higgsfield)는 만들지 않는다. 다만 각 샷에 프롬프트로 옮기기 쉬운 정보(샷 사이즈·앵글·무브·조명·색감)를 담아 둔다. 사용자가 프롬프트를 원하면 별도로 `seedance` 스킬을 쓰라고 안내한다.

---

## 작동 원칙

1. **세계관 먼저, 그다음 시간** — 세계관(톤·색·규칙)을 먼저 고정하고, 모든 샷이 그 세계관에 일관되게 묶이도록 한다. 세계관이 흔들리면 프리미엄 느낌이 무너진다.
2. **초 단위 분해** — 모든 샷은 시작/종료 타임코드와 지속 시간(초)을 갖는다. "이 영상은 멋지다"가 아니라 "0:00–0:03에 무엇이 어떻게 보이는가"로 말한다.
3. **프리미엄은 디테일에서 나온다** — 샷마다 카메라(사이즈/앵글/무브), 조명, 색감, 사운드, 연기/피사체 디렉션, 전환을 명시한다. 비워두지 않는다.
4. **복붙 가능한 표** — 출력은 마크다운 표. 그대로 노션/문서/메신저에 붙여 넣어 팀과 공유 가능.
5. **과한 길이 금지** — 사용자가 정한 총 길이를 정확히 채운다. 샷 지속 시간의 합 = 총 길이. 어긋나면 안 된다.

## INPUT 처리

사용자는 자유 형식으로 던진다. 아래를 추출하고, **빠진 핵심은 한 번에 모아 질문**한다(질문 폭주 금지).

**필수 추출:**
- **로그라인/주제** — 무엇에 관한 영상인가 (한 문장).
- **총 길이** — 초/분. 명시 없으면 플랫폼 기본값 제안(광고 15~30초 / 소셜 클립 15~60초 / 뮤비·단편 사용자 확인).
- **화면비·플랫폼** — 16:9(유튜브/TV), 9:16(릴스/쇼츠/틱톡), 1:1, 2.39:1(시네마틱). "릴스/쇼츠/틱톡"은 9:16으로 해석.
- **세계관** — 프리셋명(아래 목록) 또는 신규 정의 신호. 불명확하면 STEP 1에서 확정.

**선택 추출:**
- 톤·장르(누아르, 따뜻한 드라마, 하이텐션 광고 등)
- 타깃 시청자
- 브랜드/제품(광고일 때)
- 출연/피사체, 로케이션, 레퍼런스 작품
- 샷 분해 밀도("디테일하게" → 샷을 더 잘게, "러프하게" → 비트 단위)

첨부 이미지가 있으면 색감·톤·로케이션의 1차 근거로 삼는다.

## STEP 1 — 세계관 확정 (Worldview Lock)

세계관은 한 번 고정해서 전 샷에 적용한다. 두 경로를 지원한다.

### 경로 A: 프리셋 사용
사용자가 아래 프리셋 중 하나를 지목하거나, 요청 톤이 프리셋과 명확히 맞으면 `references/worldview-presets.md`를 읽어 해당 프리셋의 색 팔레트·조명·카메라 성향·사운드·모티프·금기를 가져온다.

내장 프리셋: **사이버펑크 네오느와르 / 다크 판타지 / 레트로웨이브 80s / 시네마틱 네이처 다큐 / 미니멀 럭셔리 / K-감성 일상 드라마 / 포스트 아포칼립스 / 클린 테크 광고**.
(목록·세부는 `references/worldview-presets.md` 참조. 새 프리셋을 추가하고 싶다는 요청이 오면 같은 양식으로 그 파일에 추가한다.)

### 경로 B: 신규 정의
프리셋에 없거나 사용자가 직접 만들고 싶어 하면, 아래 6개 축으로 세계관을 정의한다(모르는 항목은 로그라인 기반으로 합리적 기본값을 채우고, 한국어 해설에서 가정한 부분을 밝힌다):

1. **시대·장소** — 언제, 어디. (예: 2087년 침수된 도쿄 / 무국적 미니멀 스튜디오)
2. **색 팔레트** — 메인 2~3색 + 강조 1색. (HEX 또는 색명)
3. **조명 성향** — 광원 성격, 대비, 시간대. (예: 차가운 네온 + 깊은 그림자, 저녁)
4. **분위기·톤** — 감정의 결. (예: 고독하지만 우아한)
5. **세계 규칙·모티프** — 반복 시각 요소, 물리 법칙, 상징. (예: 항상 비, 홀로그램 광고, 거울 반사)
6. **금기** — 이 세계관에서 절대 안 쓰는 것. (예: 따뜻한 노란빛, 핸드헬드 흔들림)

두 경로 모두, 확정된 세계관을 **세계관 시트 표**로 먼저 출력한다(아래 출력 포맷 참조). 이게 전 샷의 헌법이 된다.

---

## STEP 2 — 타임라인 설계 (Beat → Shot)

총 길이를 내러티브 아크로 나눈 뒤 샷으로 쪼갠다.

1. **아크 선택** — 길이에 맞게:
   - 15~30초: Hook(0~3초) → Build → Payoff → Tag(브랜드/CTA)
   - 60초~3분: 기-승-전-결 4비트
   - 단편(3분+): 3막 구조
2. **비트를 샷으로** — 각 비트를 1~N개 샷으로. 샷 길이 가이드:
   - 기본 샷 **2~4초** (시청자가 한 정보를 흡수하는 시간)
   - 임팩트/감정 샷 **4~6초** 이상
   - 컷 빠른 하이텐션 광고는 **0.5~1.5초** 연사 가능
3. **리듬 설계** — 같은 길이 샷을 연달아 쓰지 않는다. 긴-짧은-짧은-긴 식으로 호흡을 만든다. 음악 비트/박자에 컷을 맞추면 프리미엄 느낌이 산다.
4. **합 검증** — 모든 샷 지속의 합이 총 길이와 **정확히** 일치하는지 확인. 어긋나면 샷 길이를 조정한다.

---

## STEP 3 — 샷별 디테일 분해 (초 단위)

각 샷마다 아래 항목을 채운다. 비우지 않는다 — 비면 프리미엄이 아니다.

- **타임코드** — `0:00–0:03` 형식(분:초). 영상이 60초 미만이어도 일관되게 `M:SS`.
- **지속** — 초 단위(예: 3s).
- **샷 사이즈** — ECU(익스트림 클로즈업)/CU/MCU/MS/WS/EWS 등.
- **앵글** — Eye / Low / High / Dutch / Top-down / OTS 등.
- **카메라 무브** — Static / Pan / Tilt / Dolly in·out / Truck / Crane / Handheld / Drone / Zoom.
- **화면 설명(액션)** — 프레임 안에서 무엇이 어떻게 일어나는가. 동사 중심, 구체적으로. 피사체의 동작·표정·궤적.
- **조명** — 세계관 조명 성향을 이 샷에 어떻게 적용하는가(키 라이트 방향, 대비, 실용광).
- **색감** — 세계관 팔레트 안에서 이 샷이 강조하는 색.
- **사운드/음악** — 음악 큐, SFX, 정적, 보이스오버.
- **대사/자막** — 있으면 큰따옴표로. 자막 카피.
- **세계관 연결** — 이 샷이 세계 규칙/모티프 중 무엇을 드러내는가(일관성 체크용).
- **전환** — 다음 샷으로의 컷/디졸브/매치컷/와이프/J-K컷 등.

샷 사이즈·앵글·무브·조명·색감 칸은 그대로 영상 생성 프롬프트(seedance 등)로 옮기기 쉽게 적는다.

## 출력 포맷 (ALWAYS 이 구조)

전체를 한국어로, 아래 4블록 순서로 출력한다. 자세한 채움 예시는 `references/output-template.md`를 참조(처음 만들 때 한 번 읽어 형식을 맞춘다).

### 1) 세계관 시트
```
## 🎬 [제목] — 세계관 시트
| 항목 | 설정 |
|---|---|
| 로그라인 | ... |
| 총 길이 / 화면비 | 30s / 9:16 |
| 세계관 | 프리셋명 또는 신규명 |
| 시대·장소 | ... |
| 색 팔레트 | #xxxxxx / #xxxxxx / 강조 #xxxxxx |
| 조명 | ... |
| 분위기·톤 | ... |
| 규칙·모티프 | ... |
| 금기 | ... |
```

### 2) 타임라인 개요
```
## ⏱ 타임라인 개요
| 비트 | 구간 | 역할 | 샷 수 |
|---|---|---|---|
| Hook | 0:00–0:03 | 시선 강탈 | 2 |
| Build | 0:03–0:18 | 맥락·욕구 | 5 |
| Payoff | 0:18–0:27 | 절정 | 3 |
| Tag | 0:27–0:30 | 브랜드/CTA | 1 |
```

### 3) 메인 스토리보드 표 (핵심)
```
## 🎞 스토리보드
| # | 타임코드 | 지속 | 샷/앵글 | 카메라 무브 | 화면 설명(액션) | 조명·색감 | 사운드 | 대사/자막 | 세계관 연결 | 전환 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 0:00–0:02 | 2s | ECU, Low | Static | ... | ... | ... | ... | ... | Match cut |
```
표가 너무 넓어 가독성이 떨어지면, 핵심 열(타임코드/샷·앵글/액션/조명·색감/사운드/전환)만 둔 표 + 샷별 추가 메모를 병행한다.

### 4) 사운드 & 프리미엄 체크
```
## 🔊 사운드 맵
| 구간 | 음악 | SFX | 보이스오버 |

## ✅ 프리미엄 체크리스트
- [ ] 샷 지속의 합 = 총 길이
- [ ] 모든 샷이 세계관 팔레트/조명 안에 있음
- [ ] 금기 위반 샷 없음
- [ ] 컷 리듬에 변화가 있음(같은 길이 연속 금지)
- [ ] Hook 3초 안에 시선 강탈 요소 존재
- [ ] 전환이 의미를 갖는다(매치컷/J-K컷 등)
```

마지막에 **한국어 해설** 2~4줄: 세계관·아크·리듬을 왜 이렇게 짰는지, 사용자가 가정 확인할 부분, (원하면) seedance로 샷 프롬프트화 가능하다는 안내.

---

## 품질 규칙 (어기면 프리미엄 붕괴)

- **합 불일치 금지** — 샷 지속의 총합이 총 길이와 다르면 출력 전에 고친다.
- **세계관 이탈 금지** — 어떤 샷도 팔레트·조명·금기를 벗어나면 안 된다. 벗어나야 할 서사적 이유가 있으면 그 자체를 모티프로 설명한다(예: 회상만 흑백).
- **모호어 금지** — "멋진 장면", "분위기 있게" 같은 말 대신 구체적 카메라·조명·동작으로 쓴다.
- **빈 칸 금지** — 디테일 항목을 비우지 않는다. 정보가 없으면 세계관 기반으로 합리적으로 채우고 해설에서 가정임을 밝힌다.
- **리듬 단조 금지** — 동일 지속 샷을 3개 이상 연달아 두지 않는다.
