# 세계관 프리셋 (Worldview Presets)

스토리보드 STEP 1의 "경로 A"에서 읽는다. 사용자가 프리셋명을 지목하거나 요청 톤이 명확히 맞으면 해당 블록을 가져와 세계관 시트를 채운다.
각 프리셋은 **색 팔레트 / 조명 / 카메라 성향 / 사운드 / 모티프 / 금기**를 갖는다. 금기는 그 세계관을 무너뜨리는 요소이니 샷 설계 시 반드시 피한다.

새 프리셋을 추가할 때는 아래와 동일한 양식(7줄)을 따른다.

---

## 1. 사이버펑크 네오느와르 (Cyberpunk Neo-Noir)
- **시대·장소**: 근미래 메가시티, 야간·우천. 네온 간판과 홀로그램 광고가 거리를 덮음.
- **색 팔레트**: 시안 #00E5FF / 마젠타 #FF008C / 딥 블루 #0A1A2F · 강조 핫핑크 #FF2D78
- **조명**: 강한 네온 키 + 깊은 그림자, 하이 콘트라스트. 젖은 노면 반사광, 림 라이트.
- **카메라**: 느린 돌리·트럭, 더치 앵글 가끔, 반사면 활용. 핸드헬드는 액션에서만.
- **사운드**: 신스웨이브/다크 앰비언트, 빗소리, 네온 험, 도시 소음.
- **모티프**: 비, 거울/유리 반사, 홀로그램, 김 서린 디스플레이, 외로운 실루엣.
- **금기**: 따뜻한 자연광, 화창한 낮, 파스텔, 깨끗한 흰 배경.

## 2. 다크 판타지 (Dark Fantasy)
- **시대·장소**: 중세풍 이세계, 안개 낀 숲·고성·폐허.
- **색 팔레트**: 머스키 그린 #2E3B2E / 차콜 #1C1A1F / 골드 #C8A24B · 강조 핏빛 #6E0E0A
- **조명**: 촛불·횃불 같은 실용광, 깊은 음영, 안개 산광. 로키(low-key).
- **카메라**: 무게 있는 크레인·돌리, 느린 푸시인. 정적이고 장엄하게.
- **사운드**: 오케스트라/합창, 바람, 멀리서 들리는 짐승 소리, 정적의 긴장.
- **모티프**: 안개, 촛불, 까마귀, 낡은 갑옷·문장, 룬·고대 문양.
- **금기**: 형광색, 현대 사물, 경쾌한 팝, 빠른 컷의 가벼움.

## 3. 레트로웨이브 80s (Retrowave 80s)
- **시대·장소**: 1980년대 환상판, 야자수·그리드 지평선·네온 선셋.
- **색 팔레트**: 퍼플 #7A2FF2 / 핫핑크 #FF4FD8 / 시안 #2FF3FF · 강조 선셋 오렌지 #FF7A1A
- **조명**: 그라데이션 네온 백라이트, 그리드 글로우, 소프트 헤이즈.
- **카메라**: 슬로 트래킹, 스티디캠, VHS 질감·스캔라인 옵션.
- **사운드**: 신스팝/아웃런, 게이트 리버브 드럼, 아날로그 험.
- **모티프**: 선셋 그리드, 야자수 실루엣, 크롬 타이포, 스포츠카, 별빛.
- **금기**: 칙칙한 다큐 톤, 자연주의 색 보정, 현대 미니멀 UI.

## 4. 시네마틱 네이처 다큐 (Cinematic Nature Doc)
- **시대·장소**: 현실의 자연 — 산·바다·사막·극지. 골든아워/블루아워.
- **색 팔레트**: 어스 톤 #4A3B2A / 딥 그린 #1F3D2B / 스카이 #BFE3F0 · 강조 골든 #E8A33D
- **조명**: 자연광, 골든아워 역광, 부드러운 그림자. 사실적 노출.
- **카메라**: 드론 항공샷, 슬로모션, 매크로, 긴 망원 압축. 안정적.
- **사운드**: 오케스트라 스코어, 실제 환경음(바람·물·새), 내레이션.
- **모티프**: 빛의 변화, 스케일 대비(거대한 풍경 vs 작은 생명), 패턴·질감.
- **금기**: 인공 네온, 과채도 보정, 흔들리는 핸드헬드, 빠른 점프컷.

## 5. 미니멀 럭셔리 (Minimal Luxury)
- **시대·장소**: 무국적·무시대 스튜디오 또는 모던 인테리어. 정제된 공간.
- **색 팔레트**: 오프화이트 #F2EFEA / 그레이지 #C9C2B6 / 잉크 #1A1A1A · 강조 골드 #B89150
- **조명**: 큰 소프트박스 하이키, 부드러운 그라데이션, 깨끗한 하이라이트.
- **카메라**: 정밀한 슬라이더·턴테이블, 매크로 디테일, 천천히. 완벽한 안정.
- **사운드**: 미니멀 피아노/앰비언트, 절제된 SFX, 풍부한 정적.
- **모티프**: 여백, 재질 클로즈업(가죽·금속·유리), 대칭, 느린 호흡.
- **금기**: 어수선한 배경, 채도 높은 색, 급한 컷, 잡음.

## 6. K-감성 일상 드라마 (Warm Korean Slice-of-Life)
- **시대·장소**: 현대 한국 일상 — 골목·카페·자취방·한강. 오후~저녁.
- **색 팔레트**: 웜 베이지 #E8D9C4 / 세이지 #A9B79A / 소프트 브라운 #6B5644 · 강조 선셋 #F0A868
- **조명**: 자연광 + 따뜻한 실내등, 부드러운 대비, 창가 역광.
- **카메라**: 잔잔한 핸드헬드/스티디캠, 얕은 심도, 눈높이. 친밀하게.
- **사운드**: 어쿠스틱 기타/로파이, 생활 소음(빗소리·찻잔·발걸음), 잔잔한 보컬.
- **모티프**: 창가 빛, 김 나는 음료, 손 디테일, 계절감, 골목.
- **금기**: 차가운 네온, 과장된 카메라 무브, 하이텐션 편집, 형광 보정.

## 7. 포스트 아포칼립스 (Post-Apocalypse)
- **시대·장소**: 문명 붕괴 후 황무지·폐도시, 먼지바람·잿빛 하늘.
- **색 팔레트**: 데저트 탠 #B79B7A / 러스트 #8A4A2B / 애시 그레이 #4A4A47 · 강조 톡식 그린 #9BC72B
- **조명**: 거친 태양 직사광 또는 흐린 산광, 먼지 입자광, 하드 섀도.
- **카메라**: 핸드헬드 거칠게, 와이드 황량함, 로우앵글 위압. 입자감.
- **사운드**: 인더스트리얼 드론, 바람·모래, 금속 삐걱임, 희박한 음악.
- **모티프**: 녹·먼지, 버려진 기계, 방독면, 균열, 홀로 선 생존자.
- **금기**: 깨끗한 색, 풍요로운 자연, 밝은 팝 음악, 매끈한 카메라.

## 8. 클린 테크 광고 (Clean Tech Commercial)
- **시대·장소**: 밝은 모던 공간 또는 추상 그라디언트 배경. 제품 중심.
- **색 팔레트**: 퓨어 화이트 #FFFFFF / 쿨 그레이 #E6E9EE / 블루 #2D7CF0 · 강조 브랜드 컬러(가변)
- **조명**: 하이키 균일광, 그라데이션 백드롭, 정밀한 스펙큘러 하이라이트.
- **카메라**: 매끈한 모션컨트롤, 제품 회전·매크로, 스피드 램프. 완벽 안정.
- **사운드**: 미니멀 일렉트로닉, UI 틱·우시, 깨끗한 임팩트 사운드.
- **모티프**: 부유하는 제품, 분해·조립 애니메이션, 빛 트레일, 클린 타이포.
- **금기**: 어두운 그림자, 어수선함, 빈티지·필름 질감, 채도 낮은 칙칙함.
