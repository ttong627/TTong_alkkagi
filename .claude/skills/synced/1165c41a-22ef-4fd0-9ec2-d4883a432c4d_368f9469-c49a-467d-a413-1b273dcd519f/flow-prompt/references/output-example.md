## 🧮 클립 플랜 (총 30s = 8+8+8+6)

|---|---|---|---|---|
| C1 | 8s | 0:00–0:08 | #1–#2 | 창가에 앉은 서연, 음료가 놓인다 |
| C2 | 8s | 0:08–0:16 | #3–#4 | 음료를 들어 향을 맡고 한 모금 |

## ▶ Flow 생성 순서
1. Gemini 이미지로 서연 정면·의상, 음료 제품컷 참조 이미지 준비(1~3장).
2. Flow의 Ingredients to Video에 참조 이미지 업로드.
3. C1 프롬프트 입력 → 생성 → 마지막 프레임 저장.
4. C2는 C1 마지막 프레임을 시작 프레임(Frames-to-Video)으로 설정 → 생성. C3, C4 동일.
5. 타임라인에서 C1~C4를 순서대로 이어붙이기.
