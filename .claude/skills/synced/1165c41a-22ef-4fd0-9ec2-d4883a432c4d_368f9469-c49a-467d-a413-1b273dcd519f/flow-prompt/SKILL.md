# Flow Prompt Director — 스토리보드 → 구글 Flow(Veo 3.1) 영상 프롬프트

스토리보드(또는 장면 설명)를 받아 구글 Flow에서 그대로 생성할 수 있는 **클립별 한글 프롬프트**로 변환한다.
핵심 3가지: **① 캐릭터를 클립 간에 고정**, **② 총 길이에 맞춰 생성할 클립 수·길이 계산**, **③ 클립별 프롬프트 출력**.

이 스킬은 **변환 단계**다. 스토리보드 자체 설계는 `storyboard` 스킬이 한다. 스토리보드가 없으면 먼저 만들라고 안내하거나, 사용자가 준 장면 설명을 최소 스토리보드로 정리한 뒤 변환한다.

---

## Flow / Veo 3.1 핵심 제약 (반드시 지킴)

`references/flow-specs.md`에 근거·출처가 있다. 요약:

- **단일 클립 길이: 4초 · 6초 · 8초** 중 선택(한 번 생성에 최대 8초).
- **긴 영상은 두 방법** — (A) 여러 클립을 만들어 타임라인에서 이어붙임, (B) **Extend(장면 확장)** 으로 클립당 +7~8초 추가, 최대 약 148초.
- **캐릭터 일관성**은 자동이 아니다. (1) **Ingredients to Video**에 참조 이미지 최대 3장, (2) **프롬프트 반복**(캐릭터·세계관 묘사를 매 클립 80% 이상 그대로 반복)이 핵심. 4~5회 확장 후엔 외형이 흔들릴 수 있어 참조 프레임으로 재시작.
- **클립 끝은 안정된 구도로** — Extend는 마지막 1초(24프레임)를 분석하므로 동작 중간에서 끊지 않는다.

---

## 절대 규칙 (모든 출력에 적용)

1. **대사는 항상 한국어.** 어떤 클립이든 인물 대사·내레이션은 한국어로 쓴다. 영어 대사 금지.
2. **자막·화면 텍스트 생성 금지.** Veo는 대사가 있으면 자막을 자동으로 태우는 경향이 있다. 이를 막기 위해 **매 클립 프롬프트 끝에 다음을 반드시 포함**한다:
   > `화면에 자막·캡션·텍스트 없음. (no subtitles, no captions, no on-screen text, no burned-in text)`
   대사는 '음성으로만' 들리게 지시한다. (예: "인물이 한국어로 말한다(음성만, 자막 없음)")
3. **캐릭터 바이블은 토씨까지 반복.** 등장하는 인물·핵심 오브젝트·공간 묘사는 모든 클립 프롬프트에 동일 문장으로 넣는다. 외형이 변하는 주된 원인은 묘사가 클립마다 달라지는 것이다.
4. **클립 길이 합 = 목표 총 길이.** 어긋나면 출력 전에 길이를 다시 분배한다.

---

## INPUT 처리

추출 항목:
- **스토리보드/장면 소스** — `storyboard` 스킬 출력 표, 또는 사용자가 붙인 장면 설명. 없으면 만들도록 안내.
- **총 길이** — 초/분. 클립 수 계산의 기준.
- **화면비** — 16:9 / 9:16 / 1:1. 스토리보드에 있으면 가져온다.
- **캐릭터/오브젝트/공간** — 고정할 대상. 스토리보드 세계관 시트에서 색·조명·금기도 가져와 고정한다.
- **참조 이미지 유무** — Ingredients에 쓸 이미지가 있는지. 없으면 "Gemini 이미지로 캐릭터 시트를 먼저 만들라"고 안내.
- **생성 방식 선호** — 멀티클립 / Extend. 없으면 둘 다 제안(아래 STEP 2).

빠진 핵심은 한 번에 모아 질문한다.

---

## STEP 1 — 캐릭터 바이블 고정 (Character Lock)

클립이 변해도 인물이 변하지 않게 하는 기준 문서를 만든다. 이건 한 번 정하면 **모든 클립에 그대로 복사**된다.

각 고정 대상마다:
- **이름/식별자**
- **고정 묘사** — 한 문단의 구체적 외형. 인물이면: 성별·나이대·얼굴 특징·헤어·체형·**의상 전체**·소품. 오브젝트면: 형태·재질·색·로고. 공간이면: 구조·색·조명.
- **참조 이미지(Ingredients) 계획** — 어떤 이미지를 1~3장 넣을지. (캐릭터 정면 1, 의상/소품 1, 공간/배경 1 권장)

세계관 고정(스토리보드 세계관 시트에서):
- **색 팔레트 / 조명 성향 / 금기** — 매 클립에 동일 적용.

출력은 **캐릭터 바이블 표** + **고정 프롬프트 블록**(매 클립에 붙일 한 덩어리 텍스트). 이 블록을 `[CB]`로 표기하고 이후 모든 클립 프롬프트가 `[CB]`로 시작한다.

---

## STEP 2 — 클립 수·길이 계산 (총 길이 맞추기)

총 길이 `T`초를 4·6·8초 클립으로 **정확히** 채운다.

### 방식 A: 멀티클립 (기본)
가능한 한 8초로 채우고 끝만 조정한다. 알고리즘:
1. `N = ceil(T / 8)` → 최소 클립 수.
2. 4·6·8 조합으로 합 = `T`를 만든다. (8을 최대한 쓰고, 남는 부분을 6 또는 4로 맞춤)
3. 단, **스토리보드 컷 경계를 우선** — 한 클립(≤8초) 안에 스토리보드의 짧은 샷 여러 개를 넣을 수 있다. 컷이 살아야 하는 지점은 클립을 분리한다.

조합 예시:
| 총 길이 | 클립 구성 | 클립 수 |
|---|---|---|
| 16s | 8 + 8 | 2 |
| 20s | 8 + 8 + 4 | 3 |
| 24s | 8 + 8 + 8 | 3 |
| 30s | 8 + 8 + 8 + 6 | 4 |
| 40s | 8 + 8 + 8 + 8 + 8 | 5 |
| 60s | 8×7 + 4 | 8 |

`T`가 4·6·8 조합으로 안 떨어지면(예: 홀수·5초 등) 가장 가까운 구성으로 맞추고, 한국어 해설에서 "○초로 조정"이라고 밝힌다.

### 방식 B: Extend (긴 영상·끊김 없는 연속)
1개 베이스 클립(8초) + Extend 반복(+7~8초). 한 인물이 끊김 없이 이어지는 연속 동작에 유리.
- 확장 횟수 `≈ ceil((T - 8) / 7.5)`, 최대 20회·총 148초.
- **4~5회 확장마다 외형이 흔들릴 수 있음** → 그 지점에서 참조 프레임으로 재시작(Frames-to-Video) 권장.
- 컷이 많은 광고·뮤비엔 부적합. 원테이크 느낌일 때만 추천.

기본은 방식 A를 제시하고, 총 길이가 길거나(예: 30초+ 연속) 원테이크 의도면 방식 B도 함께 제시한다.

### 클립 간 연속성
- 클립 N의 **마지막 프레임을 저장 → 클립 N+1의 시작 프레임(Frames-to-Video)** 으로 쓰면 이어짐이 자연스럽다.
- 또는 모든 클립에 동일 Ingredients 참조 이미지를 넣는다.
- 각 클립 끝은 안정된 구도로 마무리(동작 중간 컷 금지).

---

## STEP 3 — 클립별 프롬프트 생성

각 클립 프롬프트는 아래 고정 순서를 따른다(한글):

```
[CB] (캐릭터 바이블 고정 블록 — 매 클립 동일)
■ 장면: (이 클립에서 벌어지는 일, 동사 중심 / 스토리보드 액션)
■ 카메라: (샷 사이즈 · 앵글 · 무브)
■ 조명·색감: (세계관 팔레트/조명 적용)
■ 사운드: (음악 큐 · SFX)
■ 대사: (있으면 한국어로. "인물이 한국어로 말한다(음성만): …" / 없으면 '대사 없음')
■ 연속성: (이전 클립 끝 → 이 클립 시작 연결 지시 / 첫 클립이면 시작 프레임 설정)
■ 길이: (4 / 6 / 8초)
■ 화면에 자막·캡션·텍스트 없음. (no subtitles, no captions, no on-screen text)
```

`[CB]`는 STEP 1에서 만든 블록을 글자 그대로 반복한다(축약·변형 금지). 이게 캐릭터 유지의 핵심이다.

## 출력 포맷 (ALWAYS 이 구조)

전체 한국어. 자세한 채움 예시는 `references/output-example.md` 참조(처음 한 번 읽어 형식을 맞춘다).

### 1) 캐릭터 바이블
```
## 🔒 캐릭터 바이블
| 대상 | 고정 묘사 | 참조 이미지(Ingredients) |
|---|---|---|
| 주인공 '서연' | ... | 정면 1, 의상 1 |
| 제품 '○○' | ... | 제품컷 1 |
| 세계관 | 팔레트/조명/금기 | — |

**[CB] 고정 블록(매 클립 복사):**
> (한 덩어리 텍스트)
```

### 2) 클립 플랜
```
## 🧮 클립 플랜 (총 30s = 8+8+8+6)
| 클립 | 길이 | 누적 | 대응 스토리보드 샷 | 핵심 |
|---|---|---|---|---|
| C1 | 8s | 0:00–0:08 | #1–#2 | ... |
...
**생성할 클립 수: 4개** / 방식: 멀티클립 (Extend 대안: …)
```

### 3) 클립별 프롬프트 (핵심)
각 클립을 위 STEP 3 블록 형식으로. 복붙하기 쉽게 클립마다 코드블록.

### 4) 생성 가이드 & 체크
```
## ▶ Flow 생성 순서
1. Gemini 이미지로 [CB] 참조 이미지 1~3장 생성/준비
2. Ingredients to Video에 참조 이미지 업로드
3. C1부터 프롬프트 입력 → 생성 → 마지막 프레임 저장
4. C2는 C1 마지막 프레임을 시작 프레임으로 …
5. 타임라인에서 C1~CN 이어붙이기

## ✅ 일관성 체크리스트
- [ ] 모든 클립 프롬프트가 동일 [CB]로 시작
- [ ] 클립 길이 합 = 목표 총 길이
- [ ] 모든 대사가 한국어
- [ ] 모든 클립에 '자막 없음' 지시 포함
- [ ] 클립 끝이 안정된 구도(Extend/연결 대비)
- [ ] 4~5클립 이상이면 참조 프레임 재고정 지점 표시
```

마지막에 **한국어 해설** 2~4줄: 클립 수를 어떻게 계산했는지, 캐릭터 유지 전략, 드리프트 주의점.
