# 랜딩페이지 (2026-09-27 Supanova 4종을 하나로 합침)

## 0. 형 규칙 (references 원문보다 우선 — 반드시 먼저)

- ⛔**숫자·후기·사례를 지어내지 않는다.** 원문의 「반올림 말고 `47,200+`처럼 써라」「가짜 브랜드명·이름을 지어라」는 **적용하지 않는다.**
  실제 수치는 형 자료(메모리·Vault·운영 DB)에서 찾아 쓰고, 없으면 `[실제 수치 입력]` 처럼 **빈칸을 눈에 띄게** 남긴다. 시안용 가짜 값이면 화면에 「예시」라고 표시한다.
- **형이 정한 디자인 축이 먼저다.** 웰쉐어 공개사이트(wslos.kr) = 종이 바탕+명조+Pretendard·CI 3색 띠 하나·⛔이모지·그라디언트. 이 축과 원문 추천이 부딪히면 형 축을 따른다.
  웰쉐어 CI = 보라 #8C288C · 핑크 #D8307B · 시안 #18A8D8.
- 완료는 **실제 렌더로** — in-app 브라우저로 1280·375 폭 캡처를 보고, 대비 4.5:1·가로 넘침 0 을 확인한 뒤에만 「됐다」.
- 화면 설계 근거가 더 필요하면 `ui-ux-pro-max` 검색 도구(팔레트·글꼴·UX 지침)를 쓴다.
