# /조립분해 — 부품 → 영화 같은 조립·분해 영상 → Flow 화풍

> 비유: 제품 광고 촬영팀. CAD 가 부품을 깎고(`cad` 스킬), 계획표가 동작을 짜고, 촬영 감독(camera.py)이
> 카메라를 움직이고, 블렌더가 찍고, Flow 가 색보정(화풍)을 입힌다. **조립 순서의 정본은 블렌더 영상**이다.

## 0. 한눈에

| 단계 | 도구 | 결과 |
|---|---|---|
| 부품 만들기 | `cad` 스킬(cadgen) — 부품마다 `.label` · `@step` 과 `@glb` 같이 선언 | `STEP/<이름>.step` · `GLB/<이름>.glb` |
| 분해 계획 | `조립계획.json` (2절) | 누가 · 언제 · 어디로 |
| 준비 | `make.py 준비` | 장면키 · 검사 6종 · CAD 뷰어 확인용 애니메이션(`STEP/<이름>.step.js`) |
| 렌더 | `make.py 렌더` | `입체.mp4`(3D) · `도면선.mp4`(종이색 바탕 먹선) · `검수격자.png` · `검사.json` |
| 화풍 | `make.py 플로우` → 형이 Flow 에서 편집 → `make.py 플로우검사` | `플로우_화풍/` · `화풍_완성.mp4` |

설치(2026-09-15 형 승인): 블렌더 5.2.2 LTS `D:\Tools\Blender\blender-5.2.2-windows-x64` · CAD `D:\Tools\cad_venv` ·
스크립트는 기존 파이썬(Python311 — ffmpeg·OpenCV 가 있다)으로 돌린다.

## 1. 쓰는 순서

```bash
cd /d C:\Users\ttong\.claude\skills\조립분해\scripts
python make.py 준비 <조립계획.json>
python make.py 렌더 <조립계획.json> --미리보기 0,5.2,10.2
python make.py 렌더 <조립계획.json> --초안
python make.py 렌더 <조립계획.json>
python make.py 플로우 <출력폴더> --화풍 통통그림체3
python make.py 플로우검사 <출력폴더>
python -m pytest test_assembly.py -q
```

- 출력 폴더 = `다운로드\조립분해_<제목>_<월일_시분>\` — 작업마다 새로 (`--출력` 으로 바꿀 수 있다)
- `--미리보기 0,5.2,10.2` = 그 시각의 장면만 **본 품질 사진**으로 → `미리보기.png` (조명·색·구도를 수십 초 만에 본다)
- `--초안` = 절반 해상도·적은 샘플·모션블러 끔 → 전체 움직임을 빨리 본다
- 실험: 환경변수 `ASSEMBLY_TUNE='{"light":0.8,"look":"AgX - Medium High Contrast","raytrace":false}'` 로 조명·색을 바꿔 미리보기끼리 비교
- 준비 검사에 걸리면 렌더하지 않는다(`--강행` 으로 무시)
- ★cadgen 은 `PYTHONUTF8=1` 로 돌아야 한다 — make.py 가 켠다(한국어 윈도우에서 한글 주석 한 줄에 파싱 실패)

## 2. 조립계획.json

```json
{"title": "3단 받침 조립", "step": "STEP/stack.step", "glb": "GLB/stack.glb",
 "ratio": "16:9", "fps": 24, "flow": "분해후조립", "shot": "시네마", "stagger": 0.35,
 "parts": [{"label": "base", "name": "받침"}, {"label": "middle", "name": "가운데"}, {"label": "lid", "name": "뚜껑"}],
 "steps": [{"parts": ["lid"], "move": [0, 0, 40]}, {"parts": ["middle"], "move": [0, 0, 22]}],
 "timing": {"intro": 1.5, "explode": 3.0, "hold": 1.5, "assemble": 3.0, "outro": 1.5}}
```

| 칸 | 뜻 |
|---|---|
| step · glb | 계획 파일 기준 상대 경로 |
| parts.label | CAD 모델 `.label` 과 **글자 그대로** (블렌더는 GLB 부품을 **중심 위치**로 짝지운다 — GLB 안에는 이름이 없다) |
| steps | **먼저 빠지는 것부터**. `move` = 조립 자리에서 옮길 거리 [x, y, z] mm. 한 부품이 여러 단계에 나오면 차례로 더한다 |
| flow | 분해후조립 · 분해만 · 조립만 — 조립은 언제나 **분해의 정확한 역순**(나중에 빠진 것부터 들어간다) |
| shot | 시네마 · 제품광고 · 설명 (3절) |
| stagger | 앞 단계와 겹쳐 출발하는 정도 0~0.9 (0 = 하나 끝나고 다음 — 기계적) |
| timing | 등장·분해·멈춤·조립·마무리 초 · 전체 60초 이하 · ratio 16:9 / 9:16 · fps 24·25·30 |

## 3. 영화 느낌 자동 연출 (camera.py)

| 연출 | 렌즈 · 조리개 | 움직임 |
|---|---|---|
| **시네마**(기본) | 50mm · f/2.8 | 원테이크 — 천천히 돌며 등장 → 벌어지는 동안 크레인 업 → 멈춰 보여줌 → 내려오며 밀고 들어가 로우앵글 |
| 제품광고 | 85mm · f/2.0 | 넓게 도는 궤도 · 낮은 앵글 · 얕은 심도 |
| 설명 | 35mm · f/11 | 거의 고정된 3/4 시점 · 아주 느린 밀기(교육용) |

- 구간 끝마다 방향·높이·거리 표 → **속도가 이어지는 단조 3차 곡선** — 구간마다 멈췄다 가지 않고, 시작·끝만 부드럽게 선다
- **자동 구도**: 모든 장면에서 모든 부품 모서리가 안전 영역(가장자리 5% 안쪽) 안 — 연출이 밀고 들어가도 넘치면 **그만큼만** 물러선다
- 부품이 벌어지기 **0.6초 전부터** 미리 물러서고 줌은 부드럽게만 · 수평 유지 · 겨냥점은 부품 전체의 중심을 부드럽게 따라간다
- 입체 촬영장: 어두운 스튜디오 · 바닥 반사·그림자 · 주광·보조광·윤곽광(세상에 고정 — 카메라가 돌면 빛이 면을 타고 흐른다) ·
  색 AgX 중간 높은 대비 · 심도(초점 = 겨냥점) · 모션블러
- 도면선: 워크벤치 법선 매트캡 + 부품 외곽선 → 경계 검출 → 종이색 바탕 먹선 (같은 카메라)

## 4. 검사 — 무엇을 잡나

| 검사 | 단계 | 잡는 것 |
|---|---|---|
| 부품 수 | 준비 | STEP 부품 수 ≠ 계획 parts (빠진 부품은 제자리에 남는다) |
| 되감기 | 준비 | 조립 상태로 끝나야 하는데 안 돌아옴 |
| 부품끼리 파고듦 | 준비 | 이동 방향·거리·순서가 틀려 뚫고 지나감 — ⚠️상자 검사라 구멍 속 볼트는 못 잡을 수 있다 |
| 카메라 이음매 · 튐 · 급한 줌 | 준비 | 구간 표 끊김 · 초당 40도 넘는 회전 · 초당 60% 넘는 거리 변화 |
| 화면 잘림 | 준비 | 장면마다 부품 상자 모서리 8점 |
| 장면 수 · 영상 길이 · 검은 화면 · 선 없음 | 렌더 | 블렌더·ffmpeg 가 조용히 실패한 것 |
| 블렌더 투영 대조 | 렌더 | 블렌더가 계산한 화면 위치 ↔ camera.py 투영 — 0.01 넘게 다르면 잘림 검사를 믿지 않는다 |
| 검수격자 | 렌더 | **눈으로 본다** — 숫자만으로 끝내지 않는다 |

## 5. Flow 화풍 입히기 (flow_pack.py)

- Flow **Gemini Omni Flash 1.1 「기존 영상을 활용한 AI 편집」 = 최대 10초**(공식 도움말 09-15) →
  `입체.mp4` 를 **구간 경계에서** 10초 이하로 자른다(조각 수 최소 · 너무 짧은 조각 방지)
- 편집 프롬프트: 카메라·타이밍·부품 수·모양·위치·움직임은 원본 그대로, **겉모습만** 바꾼다 · 사람·손·글자 금지 · `/플로우` 금지어 문지기 통과
- 화풍 = `/그림도구` 통통그림체 0~3 정본에서 **렌더링 문장만** 남긴다(인물·얼굴·손·옷 문장 제거)
- ⚠️**통통그림체3 기준 그림은 통통이 캐릭터 시트** → 넣지 않는다(Flow 가 통통이를 끼워 넣는다). 필요하면 캐릭터 없는 같은 화풍 장면을 따로 고른다
- 받은 클립 검사: 윤곽선 구조 닮음 vs **같은 영상의 다른 순간** 기준선 · 길이 · 화면비 · `05_대조/` 그림 · 다 모이면 `화풍_완성.mp4`
- ⚠️숫자 기준은 첫 실측 뒤 보정한다 · 버튼 이름은 공식 도움말 표현 — 화면에서 확인 · 생성 버튼은 형이 누른다
